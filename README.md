# 🩺 ReveMed — MVP

Aplicação Web Progressiva (PWA) focada na revisão teórica e prática de conteúdos médicos para profissionais e estudantes em preparação para provas de residência e revalidação.

## 🎯 Objetivo do Projeto
Oferecer uma plataforma leve, responsiva e acessível para estudos rápidos em intervalos de plantão, mitigando a fadiga visual e otimizando o tempo de preparação.

## ♿ Acessibilidade e Impacto Social
- **Alinhamento ODS 4:** Promoção de educação inclusiva, equitativa e de qualidade.
- **Conformidade RNF04 (WCAG 2.1 AA):** Áreas de toque ampliadas ($\ge 44\text{ px}$), alto contraste e redundância multimodal nos feedbacks (cor + ícone + texto).

- `/src`: Código-fonte do MVP.
